## 🧪 Security Engineering Projects

These are project ideas and reference implementations to build out. Link each project only after the repository exists and contains the described work.

### 01 · Microsoft Entra ID Conditional Access Baseline

**[View repository](https://github.com/hiteshrr19/entra-ca-baseline)**

A practical baseline for planning and validating identity access controls.

- Document Conditional Access objectives and policy scope.
- Use report-only mode to assess impact before enforcement.
- Document emergency-access accounts and lockout safeguards.
- Add setup instructions, validation steps and rollback guidance.

`Microsoft Entra ID` `Conditional Access` `Identity Security`

### 02 · Privileged Identity Audit

**[View repository](https://github.com/hiteshrr19/entra-graph-privileged-audit)**

A project to review privileged directory role assignments and identify access that may need further investigation.

- Document privileged role assignments and standing access.
- Define a review process for potentially inactive admin accounts.
- Produce clear, reviewable audit output.
- Document Microsoft Graph permissions and least-privilege considerations.

`Microsoft Entra ID` `Microsoft Graph` `IAM`

### 03 · Azure Key Vault Security Baseline

**[View repository](https://github.com/hiteshrr19/azure-keyvault-baseline)**

A baseline for improving secrets management and configuration security in Azure.

- Configure appropriate access controls using Azure RBAC.
- Document purge protection and recovery safeguards.
- Review network access and diagnostic logging.
- Validate the configuration with Bicep when implemented.

`Azure Key Vault` `Azure RBAC` `Bicep` `Cloud Security`

### 04 · Multi-Cloud Security Checklist

**Suggested future project**

A practical checklist for reviewing common security settings across Azure and AWS.

- Identity and least-privilege access.
- Public exposure of storage and services.
- Logging, monitoring and audit trails.
- Encryption, backup and recovery.
- Documented findings and remediation steps.

`Microsoft Azure` `AWS` `Security Baselines`
