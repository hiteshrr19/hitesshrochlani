I'm a cloud and infrastructure professional with **11+ years of enterprise IT experience**, building on a background in IT operations, cloud administration, identity management, and enterprise support.

My technical interests focus on the intersection of **cloud infrastructure, identity security, and automation** across Microsoft Azure and AWS.

- **Identity & Access:** Microsoft Entra ID, Conditional Access, MFA, RBAC, PIM and identity governance.
- **Cloud Security:** Secure configurations, least privilege, policy enforcement, monitoring and security baselines.
- **Infrastructure as Code:** Terraform, ARM/Bicep and repeatable infrastructure deployment.
- **Automation:** PowerShell, Python and Microsoft Graph API.
- **Cloud Platforms:** Azure, AWS, Microsoft 365 and VMware.

I'm focused on turning security principles into practical, repeatable engineering solutions.

## Featured Security Engineering Projects

Projects should demonstrate implementation, testing and documented outcomes—not just architecture diagrams.

### 01 · Microsoft Entra ID Conditional Access Baseline

**Repository:** [entra-ca-baseline](https://github.com/hiteshrr19/entra-ca-baseline)

A reference framework for implementing identity access controls with a controlled rollout strategy.

- Define Conditional Access policies and security objectives.
- Evaluate policies in report-only mode before enforcement.
- Document emergency-access exclusions and lockout safeguards.
- Include deployment instructions, validation steps and rollback guidance.

`Microsoft Entra ID` `Terraform` `Zero Trust` `IAM`

### 02 · Privileged Identity Audit

**Repository:** [entra-graph-privileged-audit](https://github.com/hiteshrr19/entra-graph-privileged-audit)

A Python and Microsoft Graph-based approach to identifying privileged access risks.

- Inventory privileged directory role assignments.
- Highlight standing assignments and potentially inactive administrative accounts.
- Produce reviewable audit output for remediation.
- Document API permissions, limitations and least-privilege requirements.

`Python` `Microsoft Graph API` `Entra ID` `PIM`

### 03 · Identity Threat Detection with KQL

**Repository:** [entra-kql-detections](https://github.com/hiteshrr19/entra-kql-detections)

A collection of identity-focused detection queries designed for investigation and threat hunting.

- Investigate suspicious sign-in patterns.
- Identify risky authentication and account activity.
- Document query prerequisites, data sources and expected results.
- Include sample events and testing instructions where available.

`KQL` `Microsoft Sentinel` `Identity Security` `Threat Hunting`

### 04 · Azure Key Vault Security Baseline

**Repository:** [azure-keyvault-baseline](https://github.com/hiteshrr19/azure-keyvault-baseline)

A reusable baseline for strengthening secrets management in Azure.

- Apply Azure RBAC and least-privilege access.
- Configure purge protection and appropriate recovery safeguards.
- Define network access and diagnostic logging controls.
- Validate configuration through infrastructure-as-code workflows.

`Azure Key Vault` `Bicep` `GitHub Actions` `Cloud Security`
